## Mapping decisions

| Domain | Table | Column notes |
|---|---|---|
| `Event` | `Events` | `EventId` is the PK (no surrogate); issuer/recipient/match/winner use `nvarchar` + `Latin1_General_100_BIN2` so comparison stays ordinal; `CreatedAt` stored through `UtcConverter` |
| `UserPreference` | `UserPreferences` | composite PK `(Issuer, Subject)`, both `nvarchar` + binary collation |

Indexes:
- `IX_Events_Issuer_UserId_CreatedAt` — serves "my events" (issuer + recipient, newest first).
- Primary key on `Events.EventId` doubles as the idempotency key.
- Primary key on `UserPreferences (Issuer, Subject)` doubles as the opt-in lookup.

## Repository behaviour

**`EventRepository.AddAsync`**
1. Read by `EventId`.
2. `EventReplayPolicy.Resolve(existing, candidate)` decides: new → insert, identical → return
   the stored event (including its original `CreatedAt`), different → `EventConflictException`.
3. A concurrent insert that wins the race is recovered by catching the duplicate-key error
   (2601/2627), detaching the candidate and re-running the same decision against the winner.

**`UserPreferenceRepository.UpsertAsync`** — load or insert, apply the flags, save; the
duplicate-key race falls back to a second attempt against the stored row.

Reads use `AsNoTracking()`; every method takes and forwards a `CancellationToken`.

## Migration

The migration must be generated by tooling:

```powershell
dotnet ef migrations add AddEventsAndPreferences `
  --project src/QuizArena.Notification.Data `
  --startup-project src/QuizArena.Notification.Api `
  --context NotificationDbContext
```

(Not generated in this branch because the authoring environment cannot restore packages —
`Microsoft.AspNetCore.Authentication.JwtBearer` is not cached and nuget.org is unreachable.)

## Validation

```powershell
dotnet build QuizArena.sln
dotnet test  tests/QuizArena.Notification.IntegrationTests
```

The relational tests create a uniquely named SQL Server database per test and drop it
afterwards; `QUIZARENA_TEST_SQLSERVER` overrides the LocalDB default.
