## Behavior
- Routes are keyed by the session subject from the validated token. The client never takes a user id from input.
- Statistics: totals (games, wins, win rate, score); history 10 per page, newest first, Newer/Older; empty states; no result-submission form (results are written only by Gameplay).
- Leaderboard: top 10/25/50/100, signed-in player marked "You", empty state.
- Profile: 404 means "no profile yet", so the form is prefilled with the token name; local validation (trimmed, 1–80); saving state with double-submit guard; server 400 field errors shown on the field; sign-out through the provider. No password form.
- Errors: 401 returns to sign-in; 403 shows the permission message with no retry; 503/network/unexpected offer "Try again"; malformed responses become errors instead of rendering.
