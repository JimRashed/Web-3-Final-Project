# Issues #31 (S01-T06) and #37 (S02-T06): Identity and Statistics vertical-slice coverage audit

Parents F01 #9 and F02 #10, epic #7. Prerequisites: #29/#35 (endpoints, merged), #30/#36 (screens, PR #102), #24 (P09 test hosts, closed).

## Method
I listed every existing test in the Identity and Statistics unit, integration and client suites, mapped each acceptance criterion to the tests that prove it, and added tests only where a criterion had no proof on the **real routes**. The security matrix suites existed already, but they exercised a probe controller only.
